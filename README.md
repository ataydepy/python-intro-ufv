# Introdução à Programação - UFV
Exercícios e listas da disciplina Introdução à Programação – Python

Este repositório reúne todas as listas de exercícios da disciplina Introdução à Programação da Universidade Federal de Viçosa (UFV), utilizando Python. Ele foi organizado para facilitar o estudo, com cada lista em sua própria pasta e arquivos com nomes descritivos.

Além das listas, há uma pasta de projetos extras e exercícios opcionais, permitindo praticar conceitos e explorar ideias adicionais.

O objetivo deste repositório é servir como registro de aprendizado e referência para futuras revisões, mantendo todo o conteúdo organizado e fácil de acessar.

Novos códigos serão postados de acordo com as novas listas, e os arquivos em .pdf das listas também serão disponibilizados.
